KVA software Far+IntelliMouse version 1.0
-----------------------------------------

1. FarIntel is small utility, which allows to use wheel of 
   Microsoft IntelliMouse or Logitech WheelMouse in 
   File and Archive Manager (FAR) as well in any console 
   applications.

2. Requirements:
   Windows NT 4.0 with Service Pack 3.0 or later.			

3. To Install FarIntel

   a. Download FarIntel utility 
		http://www.uran.net/kva/exe/FarIntel10.zip
   b. Create a folder for FarIntel ( such as C:\Program Files\FarIntel )
   c. Unzip file FarIntel.zip to this folder
   d. Run FarIntel.exe

4. To UnInstall FarIntel

   a. Stop FarIntel application using Windows Task Manager 
   b. Delete FarIntel folder
