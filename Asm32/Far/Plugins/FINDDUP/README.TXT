1. Назначение

 Модуль FindDup.dll является плагином для файлового менеджера Far
и предназначен для поиска одинаковых файлов и каталогов на всех
дисках компьютера. Для ускорения поиска используется алгоритм
сравнения с использованием сумм MD5. Данная версия плагина
достаточна глупа и имеет минимум настроек (см. exlude.txt и
include.txt). Принудительно обходятся все диски, но некоторые
диски или каталоги можно исключить из поиска задав маску в файле
exlude.txt. Примеры:

D:\* - исключить из поиска диск D;
*\windows\* - исключить из поиска каталог windows.

С версии 0.05 добавлена возможность поиска только в указанных
директориях, для этого создайте файл SearchPaths.txt c перечнем
всех полных путей к директориям в каталоге с плагином (пути всегда
должны завершаться '\').

 Также можно задать поиск файлов по маскам в файле include.txt.
Внимание! Маски в файле exlude.txt действуют только на каталоги,
а в файле include.txt - только на файлы.

 По клавише F7 можно скрывать с панели лишние файлы или группы.
Внимание! Если в группе после операции скрытия осталось менее
двух файлов, то такая группа скрывается автоматически.

 Переключение в режим поиска одинаковых директорий включается
созданием пустого файла FindDupDir.flg в каталоге плагина, возврат
в режим поска файлов - его удалением. Только не надо говорить, что
диалоги удобнее - все будет, но в свое время.
Обратите внимание! На поиск дубликатов директорий влияют маски включения
и исключения, точнее будут отброшены все поддиректории и файлы не
подпадающие под маски и лишь затем произведено сравнение.

С версии 0.06 добавлена возможность просмотра списка файлов/каталогов
не имеющих дубликатов - переключение режимов показа CTRL+ALT+F3.

2. Инсталляция

 Скопируйте файлы FindDup.dll, *.lng, *.txt в каталог
"FAR\Plugins\FindDup", перезапустите Far.

3. Использование

Запуск осуществляется через меню плагинов: F11->Поиск дубликатов или
F11->Find Duplicate.
