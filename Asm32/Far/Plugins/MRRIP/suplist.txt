Список поддерживаемых форматов
Mr.Ripper v0.20 alpha 6 (30,46)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Графика

  BMP  - Microsoft bitmap files
  DjVu - Многостраничный формат AT&T
  GIF  - Статические и анимированные изображения CompuServe
  JPEG - Сжатое изображение
  LBM  - IFF, содержащий графику
  PCX  - ZSoft image file
  PNG  - Portable Network Graphics image
  TGA1 - несжатое изображение с палитрой
  TGA2 - несжатое изображение без палитры

Звук

  AIFF - IFF, с аудиоданными
  AU   - Sun sound files (используется в *nix системах)
  MPEG - MP3, MP3Pro, VBR
  OGG  - Ogg Vorbis
  WAV  - Microsoft sound files


Музыка

  IT   - Impulse tracker files
  MIDI - команды MIDI
  MOD  - ProTracker files
  MUS  - упрощенный аналог формата MID
  S3M  - ScreamTracker 3 files
  ULT  - UltraTracker modules (все версии)
  XM   - Extended module files
  XMI  - IFF, с командами MIDI

Видео

  AVI - Microsoft Audio Video Interlaced files
  BIK - RadGame Tools Bink video files
  SMK - RadGame Tools Smacker video files

Текст

  PDF - Электронные книги Adobe
  RTF - Microsoft RichText format files

Прочее

  IFF  - Формат, подобный RIFF
  RIFF - Microsoft multimedia format files
