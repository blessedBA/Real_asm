SIT.FMT
ver 1.0 betta  13.09.1999
---

FMT-модуль SIT.FMT позволяет вам просматривать SIT-архивы (от Apple Inc.)
Обычно такие архивы, предварительно сконвертированные в BinHex-формат,
необходимы для случая, когда необходимо обменяться информацией (например
через Интернет) с теми, у кого стоит Mac OS.

Консольных архиваторов для работы с SIT-архивами я в Интернете не встречал,
только GUI (фирма Alladin раздает freeware облегченный по адресу ).
Хотя, если у кого хватит терпения собрать из исходников вполне
работоспособный консольный unpack`ер, то сходите сюда:

  http://ilm.mech.unsw.edu.au/tex-archive/tools/macutils/

Распаковщик можно найти в "Aladdin Systems":

  http://www.aladdinsys.com/downloads/index.html

Но он имеет GUI интерфейс, так что...
... а утилита из macutils не может... вот, читайте из переписки с автором:

-- 8< -------------------------------------------------------------------
 > In any event command (with any parameters):
 >   macunpack stuff.sit
 > gives following lines:
 > ...
 > Unknown compression methods: d d, skipping file.
 > Unknown compression methods: d d, skipping file.
 > Unknown compression methods: 0 d, skipping file.
 > ...

I know.  The later Stuffit versions can use a compression method that I
have not yet been able to decode.  Alladin is also not willing to
publish the method, so I am not yet able to include this compression
method in macunpack, alas.
-- >8 -------------------------------------------------------------------

Внимание!
~~~~~~~~~
 Версия является (на мой взгляд) "сырой бэттой", т.к. в моем рапоряжении
 было только пара SIT-архивов (хотя "отработали" они без проблем). Если
 будут какие нарекания по-поводу работы данного модуля, то обязательно
 напишите мне, описав ситуацию, приведщую к нестабильной работе, и, если
 SIT-архив не более 60К, то и его приложите к письму (или укажите точный
 адрес в Интернете).
