	To install an "Advanced File Select" plugin:

        1. Go to  $(FAR)\Plugins\  folder
        2. Create "AdvSel" folder (or something else)
        3. Copy all files from archive into this folder
        4. Restart FAR manager
        5. Have a nice plugin :-)
