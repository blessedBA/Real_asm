                    Branch v1.4 plugin for FAR 1.60

 Возможно, некоторые пользователи DosNavigator'а помнят его возможность строить
"Ветвь каталога",  т.е.  список  из  всех   файлов  текущего   каталога  и  его 
подкаталогов.  Это может пригодиться для поиска, удаления или копирования групп
файлов расположенных в разных  подкаталогах.  Также это может  понадобиться для
очистки  ветви  каталога,  т.е.  удаления  файлов  без удаления  самого  дерева
каталогов.
 Данный  плагин  воссоздает эту возможность.  При желании в  его  панели  могут
отображаться имена не  только  файлов,  но  и подкаталогов. Переход к файлу, на
котором стоит курсор - Ctrl-PgUp.


Отличия от версии 1.3:
- Исправлена ошибка проявляющаяся на каталогах в которых не  доступно ни одного
  файла или каталога  (корень пустого диска,  каталог сетевого диска с запретом
  доступа на чтение и т.п.);
+ Добавлены  фильтры для файлов и  каталогов.  Если имя каталога  соответствует
  одной из заданных масок -  в панели плагина не будет ни этого каталога ни его
  содержимого.  Это может пригодиться, например, пользователям ZipFolders. Файл
  не отображается в панели,  если он соответствует  одной из масок.
  При задании масок необходимо учесть,  что ни пробелы ни какие другие символы,
  кроме разделяющих запятых, не игнорируются и считаются частью маски;
+ Добавлен новый режим  ("Показывать только выделенное").  В этом режиме плагин
  отображает только содержимое выделенных подкаталогов (и выделенные файлы).
  Так что теперь в списке команд плагинов две команды для Branch;
+ В режимах 5 и 7 теперь отображаются файлы с полными путями;
+ Для страдающих  отсутствием файла msvcrt.dll - добавлена версия  не требующая
  его для своей работы (находится в архиве womsvcrt.rar).
