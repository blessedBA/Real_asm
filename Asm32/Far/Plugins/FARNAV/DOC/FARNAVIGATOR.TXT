  II. Introduction

  Features on this moment:

  *  work with FTP (user@site style), HTTP or SOCKS proxy server;
  *  receive/send/delete files and folders;
  *  rename files (FTP mode only);
  *  server to server transfer mode
  *  resume function with copy/move;
  *  change file permissions/owner (FTP mode only);
  *  send command line directly to FTP server (FTP mode only);
  *  customize connection timeout and idle timeout;
  *  language tables support
  *  and more...
