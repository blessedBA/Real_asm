  II. Что это такое?

  На данный момент этот модуль позволяет:

  *  работать с HTTP серверами
  *  работать с FTP серверами с использованием различных типов прокси-серверов
     HTTP/FTP/SOCKS.
  *  принимать/отправлять/удалять файлы и каталоги на FTP серверах.
  *  переименовывать файлы (только при работе без HTTP прокси);
  *  передавать файлы напрямую от сервера к серверу (только при работе без
     HTTP прокси);
  *  восстанавливать прерванное копирование.
  *  изменять атрибуты файлов (только при работе без HTTP прокси);
  *  передавать командную строку напрямую к серверу (только при работе без
     HTTP прокси);
  *  гибко настраивать параметры соединения (время простоя, количество попыток,
     пауза между попытками и прочее)
  *  поддержка таблиц символов.
  *  и многое, многое другое...
