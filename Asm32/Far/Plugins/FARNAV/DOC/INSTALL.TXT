 How to install:
  1. Exit from all FAR copies.
  2. Run "Windows Explorer"
  3. Make "ProxyFTP" directory in "FAR\Plugin" directory
  4. Copy files from this archive to "ProxyFTP" directory
  5. Run FAR and select menu "Options"/"Plugins configuration"/"ProxyFTP client"
  6. Define your options and proxy settings
  7. In "File panels" press ALT+F1/F2 (or F11) and select "ProxyFTP client".
