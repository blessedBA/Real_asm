What is it?
ÄÄÄÄÄÄÄÄÄÄÄ
	This plugin allows to transcod selected cyrillic text files and change
	EOLs to DOS (CR+LF) or UNIX (LF) style. Supported Russian codepages:
	DOS Cp866, Windows Cp1251, KOI-8, Unix ISO 8859-5, Macintosh, Java Unicode
	(native2ascii equivalent), UTF-8. Plugin also supports registered in FAR
	code tables.


What's new?

	       Nothing. Plugin simply works :-)

How to:
ÄÄÄÄÄÄ
Select files to transcod in FAR pane.
To call the plugin press F11 key and select "Transcod" item.
Dialog will appear.
Select source and target codepages, EOL type, other options, and then click OK.
