Назначение:
───────────
	Плагин позволяет быстро перекодировать кириллицу в выбранных текстовых файлах,
	а также поменять формат конца строк на DOS (CR+LF) или UNIX (LF).
 В плагин встроены следующие русские кодовые таблицы:
	DOS Cp866, Windows Cp1251, KOI-8, Unix ISO 8859-5, Macintosh, Java Unicode
 (эквивалент native2ascii), UTF-8.
 Плагин также работает с таблицами, зарегистрированными в FARе.

Что нового?

	В версии 1.02:

Действие:
─────────
На панели FARа выберите файлы, которые требуется перекодировать.
Для вызова плагина нажмите клавишу F11. 
Из меню установленных плагинов выберите строчку Перекодировка файлов/Transcod.
В появившемся диалоге выберите исходную и требуемую кодировки, тип EOL и
нажмите кнопку ОК.
