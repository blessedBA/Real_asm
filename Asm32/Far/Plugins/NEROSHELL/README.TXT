Плагин   для   FAR  позволяющий  записывать обычные и мультисессионые CDR и
CDRW диски.

Установите   файлы   из   архива   в  предварительно  созданную  директорию
..Far\Plugins\NeroCmd    и  перезапустите  FAR. После этого в меню плагинов
вызываемого  по  F11 появится пункт >NeroCmd shell<, который нужно выбирать
чтобы запустить программу.

Плагин представляет собой оболочку для запуска утилиты командной строки для
записи  CD\CDRW, входящюю в состав программы Nero - Burning ROM фирмы Ahead
Software  AG.  Соответственно, для работы плагина на компьютере должны быть
установлены привод CDRW и программа Nero - Burning ROM.

Перед  записью  необходимо  отметить файлы и директории предназанченный для
записи.

При  запуске  плагина  по  F11  появляется  меню,  состоящее  из 8 пунктов,
"Erase",  "Quick  Erase"  -  стирают  диск  полностью  и  в  ыбстром режиме
соответсвенно.  "Load  CD"  и  "Eject  CD"  -  управляют лотком CD привода.
"Drives   list"   позволяет   получить  список  приводов  установленных  на
компьютере.  "Get  CD  Info"  - получает информацию о диске установленном в
привод.
Непосредственно запись диска осуществляется выбором пункта меню "Write CD".
После   выбора  этого пункта меню Вам предлагается выбрать, букву диска CDR
или   название   CD   ROM  выдаваемое  по  List  drives  (например  MITSUMI
CR-48XATE),  обычный  или  мультисессионный  диск, скорость записи и режимы
записи.

Пункт "Write" указывает производить реальную запись или симуляцию записи.
"Multisession" - выбор записи мультисессионного диска
"Finalize" - финализировать диск (для немультисессионного диска)
"Underrun protection" - защита от опустошения буфера записи
"No eject after burning" - не выдвигать лоток диска после записи, (если не
перезагрузить диск в лотке, не будет видна последняя записанная сессия)
"TAO" - режим "Track at once" (для немультисессионнных дисков)
"Detect speed" - определение возможной скорости записи
"Verify after burning" - проверка диска после записи.
"Run in separate window" - запуск прожига в отдельном окне.
"Mode 2" запись диска в Mode 2
"keep select" оставлять папки и файлы на панели выбранными
"Force erase non empty CDRW" - стирать не пустые CD-RW.



Если  скопировать  в директрию плагина файлы atipc.exe и mid.csv, то в меню
программы  после  пункта  "About"  появится  пункт "ATIP". При выборе этого
пункта   запустится   программа   atipc.exe,  которая  попытается  получить
служебную  информацию  с  CDR  диска,  в  частности  компанию производителя
матрицы дисков, полную емкость диска итд.
Для работы модуля может понадобиться установить ASPI драйвера, например,
ForceASPI.


Плагин   предназначен   для   быстрой   удобной   записи   дисков  и  может
использоваться  в простейших распространенных случаях, например, добавление
сессии, запись архивов или копий файлов с винчестера.

Плагин тестировался с версиями 5.5.8.0, 5.5.8.2 и 5.5.9.9.


Ограничения
===========
1. На данный момент под Win 2000 функция ATIP, к сожалению, не работает.
2. Мне  не  удалось  найти  сочетание  ключей  nerocmd,  при котором будет
импортироваться  информация  о  кодовой таблице символов в именах файлов из
предыдущих сессий, поэтому если на диске были сессии с русскими символами в
именах  файлов,  то  эти  имена фалов после записи новой сессии испортятся.
Поэтому, желательно не записывать при помощи этого плагина файлы и каталоги
с русскими именами или записывать их только как последнюю сессию.
