Changes from original
---------------------

1. Plugin is started with file panel and from built-in editor

2. When start from file panel:
- Enter,Escape(keyboard), DoubleClick(mouse) - exit
- Shift+Enter(keyboard), Shift+DoubleClick(mouse) - symbol - to ClipBoard

3. When start from built-in editor:
- plugin start on symbol, to which indicate cursor in editor
- appears table of symbols, which corresponds to current codepage
- Escape(keyboard) - exit
- Enter(keyboard), DoubleClick(mouse) - insertion symbol in current position
- Shift+Enter(keyboard), Shift+DoubleClick(mouse) - symbol - to ClipBoard
