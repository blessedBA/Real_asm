Плагин "Torrent Info" для Far Manager 3.0
*****************************************

Плагин, позволяющий просматривать содержимое торрент файлов (*.torrent).
Дополнительная информация о торренте (info hash, magnet link и т.д.)
доступна по F7 (Dump).

Установка:
  Распакуйте содержимое архива в каталог плагинов Far (...Far\Plugins).

Хозяйке на заметку:
