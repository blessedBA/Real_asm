MchQHFView v.1.1.0.4
=====================

Плагин для Total Commander, позволяющий просматривать содержимое файлов
истории QIP PDA, QIP Infium (*.QHF; *.AHF) по клавишам F3, Ctrl+Q.

При открытии архива с plug-in'ом в Total Commander, последний спросит,
устанавливать plug-in, или нет.

Если авто-установка не срабатывает, то для установки нужно в Total Commander'е зайти в меню Configuration / Options /
Plugins / Lister plugins (.WLX) / Configure / Add, и в открывшемся окне
выбрать файл "MchQHFView.wlx".

После этого встроенный листер TC начнет показывать файлы QHF в читабельном виде.


Новое в версии 1.1.0.4:
-----------------------
- Реализована поддержка нескольких копий просмотрщика (прежние версии валились
при попытке открыть второе окно);


Новое в версии 1.1.0.3:
-----------------------
- Теперь плагин реагирует на файлы архивов (*.AHF);

- Показатель процентов обновляется при прокрутке текста;

- Возможность перехода по ссылкам в тексте.


Новое в версии 1.1:
-------------------
 - При наличии в папке плагина файла template.rtf, он будет использован как шаблон
для вывода текста. Формат шаблона очевиден, и не нуждается в отдельном описании,
замечу только, что для редактирования лучше не пользоваться MS Word'ом, но
использовать MS WordPad, или же Notepad;

- Значительно увеличен максимальный допустимый размер отображаемого файла;

- Заработал поиск по тексту (Find text (F7), Find next (F5)); (При поиске текста
в кириллице переключайте язык ввода на нужный);

- Автоматическая подсветка URL'ов.


P.S. Корректное отображение возможно только для файлов QHF версий 1,2,3.
Если версия файла не поддерживается, то вы увидите файл так, как если бы плагин
не был установлен вообще.
