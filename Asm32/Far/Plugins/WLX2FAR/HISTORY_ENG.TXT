version 0.0.4 (12/05/2005)
--------------------------
 + Autosearch wlx plugins in subfolder "Plugins" (suggested by Alex Yaroslavsky
   at yandex.ru / trexinc)
 + Autosearch command wlx2far:searach with path argument
 + Dynamic load/unload wlx plugins (suggested by Alex Yaroslavsky at yandex.ru / trexinc)
 + Pin lister to FAR window switch
 + Subdivide plugin file name and alias. Now plugin may called with
   alias and full file name
 * Using FSF.ExpandEnvironmentStr for default plugin mask and
   argument in opening procedure
 * Using FSF.Unquote for argument in opening procedure
 * Add new plugin from plugins menu cause to chose current
   file from active FAR panel as plugin file name
 * Open plugin in lister from plugins menu cause to chose current
   file from active FAR panel as plugin argument
 * wlx2far.ini format changed. Add plugin alias support

version 0.0.3 (09/05/2005)
--------------------------
 * Now linking with msvcrt.lib
 ! Bug fixed in plugin menu ("Show lister" instead of "Hide Lister")

version 0.0.2 (09/05/2005)
--------------------------
 + Add QView support.
 * Second public release. Changed almost everything! Now WLX2FAR run
   as true FAR plugin and working as a quick viewer tool and multitabbed lister.
 - Removed supporting of "native" gui4far plugins.

version 0.0.1 (18/04/2005)
