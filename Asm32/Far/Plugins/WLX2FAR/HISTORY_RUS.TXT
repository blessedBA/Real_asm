версия 0.0.4 (12/05/2005)
-------------------------
 + Авто-поиск wlx плагинов в каталоге "Plugins" (предложено Алексеем
   Ярославским at yandex.ru / trexinc)
 + Команда для авто-поиска wlx плагинов в указанном пути wlx2far:search
 + Динамическая загрузка/выгрузка wlx плагинов (предложено Алексеем
   Ярославским at yandex.ru / trexinc)
 + Выключатель привязки окна листера к окну FARа
 + Разделение имени плагина (alias) и имени файла плагина. Теперь
   плагин можно вызывать как по краткому имени так и по имени файла
 * Использование FSF.ExpandEnvironmentStr для установки маски и аргумента
   при запуске плагина
 * Использование FSF.Unquote для аргумента при запуске плагина
 * При добавлении нового плагина из меню его имя берется из
   текущего файла на активной панели
 * При вызове плагина из меню его аргумент берется из текущего
   файла на активной панели
 * Изменен формат wlx2far.ini. Добавлена поддержка имени плагина (alias)

версия 0.0.3 (09/05/2005)
-------------------------
 * Теперь линкуем с msvcrt.lib

версия 0.0.2 (09/05/2005)
-------------------------
 + Добавлена поддержка режима быстрого просмотра QView.
 * Второй общедоступный релиз. Практически все переделано заново! Теперь WLX2FAR
   является полноценным плагином для FAR, который работает в режиме
   панелей быстрого просмотра и в режиме листера с закладками.
 - Уделена поддержка "родных" плагинов для gui4far.

версия 0.0.1 (18/04/2005)
-------------------------
 + Первый общедоступный релиз, который не является настоящим плагином к FAR.
   Приложение используется как дополнение к консоли.  Дополнительно
   рекомендуется использование ConsoleServer Сергея Обломова.
