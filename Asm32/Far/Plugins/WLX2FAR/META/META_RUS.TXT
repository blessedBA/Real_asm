Мета wlx плагины (wlm) используются в wlx2far для
определения поддерживает ли конкретный wlx плагин
открытия данного типа файла. Для этого в мета
плагине есть 2 экспортируемые функции:

void ListGetExtensions(char* extbuffer,int bufferlength) -
     функция возвращает строку в которой записаны маски
     файлов, которые поддерживаются соответствующим
     wlx плагином.
int  ListIsSupported(const char *FileName,const char *Buffer,DWORD BufferSize) -
     функция проверяет поддерживается ли конкретный файл в wlx плагине.
     Мета плагин получает имя файла и начальный фрагмент содержимого
     файла размера BufferSize. Возвращает 0 если файл не поддерживается.

При анализе пригодности файла к имеющемуся списку wlx
плагинов и выделения одного из них для отображения
файла используется следующий подход:
1) Проверка масок установленых средствами wlx2far и
   хранимых в "wlx2far.ini" последовательно для всех
   wlx плагинов
2) Проверка масок полученных из ListGetExtensions()
   для каждого из имеющихся wlx плагинов
3) Анализ результата ListIsSupported() для каждого
   из имеющихся wlx плагинов

Для работы мета wlx плагина с обычным wlx плагином его имя должно быть
таким же как и у wlx, только расширение wlm:

myplugin.wlx - обычный wlx плагин
myplugin.wlm - связанный с ним мета плагин.

Для работы c большинством wlx плагинов можно использовать
стандартный мета wlx плагин. Этот мета плагин связывает с
соответствующим wlx плагином список расширений, которые
находятся в файле "meta.ini". Переименовав "Meta.wlm" в
соответсвии с именем вашего wlx плагина и подредактировав
"meta.ini", вы можете связать мета плагин с любым wlx плагином.
