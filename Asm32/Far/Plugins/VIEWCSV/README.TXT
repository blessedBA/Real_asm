
FAR_CSV_PLUGIN.dll - Плагин для "просмотра" CSV-файлов

"Вход" "внутрь" CSV-файла аналогично "входу" "внутрь" архивов:
стоя в панели FAR на нужном файле (в данном случае на файле с
расширением *.CSV), нажать <ENTER> или <Ctrl>+<PgDn>

 Планы развития
 ==============
1. Настройка плагина (отображение CRC в "Описании"/"Description"/):
   г===========================================¬
   ¦ Отображать CRC в описании файла           ¦
   ¦ ( ) Нет                                   ¦
   ¦ (*) Да                                    ¦
   ¦  ( ) Только при отсутствии описания файла ¦
   ¦  (*) Всегда                               ¦
   ¦   (*) Добавлять CRC перед описанием       ¦
   ¦   ( ) Добавлять CRC в конец описания      ¦
   L===========================================-
2. "Дружественный" плагин для расчета CRC (и генерации CSV-файла)
   текущей панели FAR (с учетом возможной пометки файлов и подкаталогов).
   Создавайемый CSV-файл, вероятно, помещается в этот же (текущий)
   каталог, имя CSV-файла назначается автоматически.
