The very brief description
--------------------------

This plugin allows to sum a column of numbers. The result is placed in 
Clipboard.


Installation and start
----------------------

Unpack archive in subdirectory ClipSumm of a directory Plugins or 
Plugins\Editor. Restart FAR.

The operating procedure
-----------------------

1) Allocate in the built-in editor column of numbers.
2) Press F11, cause "our" plugin - "Summator".
3) In opening dialogue check that is required - Enter. Result of addition - in 
Clipboard.
