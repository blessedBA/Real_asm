
		SelBlock - плагин для редактора FAR
		───────────────────────────────────


Назначение.

	Плагин позволяет выделять текстовый блок произвольного
размера через команды Начать/Закончить выделение, т.е. избавляет от
удерживания клавиши Shift в момент выделения блока.



Установка.

	Поместите файлы из архива в каталог:
        $(FAR)\Plugins\Editor\SelBlk
и перезапустите FAR. Рекомендуется установить горячую клавишу 'z' для
вызова плагина из меню плагинов редактора. В комплекте файл f3.reg -
устанавливает макрос на клавишу F3 для начала\завершения выделения
блока. Естественно, вы можете изменить все, что угодно! :-)
