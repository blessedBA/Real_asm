The very brief description
--------------------------

This plugin allows to sorting. The selected lines (or parts of lines) are 
sorting only. A key for sorting is the selected area always (for example, 
vertical block).


Installation and start
----------------------

Unpack archive in subdirectory SortEdit to a directory Plugins or 
Plugins\Editor. Restart FAR.

The operating procedure
-----------------------

1) Select sorted area in the built-in editor.
2) Press F11, cause "our" plugin - "String sorting".
3) In opening dialogue check that is required - Enter.
