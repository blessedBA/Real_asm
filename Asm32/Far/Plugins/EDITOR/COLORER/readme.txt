    0. Colorer  library    contains   service  methods  to   work   with
regular   expressions   (regexp)  and  lexical/syntax  highlighting.  It
distributes  freely  with  source  codes.  Colorer library is a total of
source   codes,  binaries  and  HRC-scripts,  let  having  abilities  of
syntax/lexical analyze. Some people like it.

    6. How to install colorer?
    Unpack Colorer archive into the handy directory. I recommend
  c:\program files\colorer\ for windows and
  /usr/share/colorer/ for unix systems.
Colorer need long file names and archive's directory structure - so, use
proper  archiver.  If  you've  installed  colorer  into these dirs, it's
ready  for  work. Else you need to correct bin/colorer.ini (.colorer.ini
for  unix).  you  need  this  to  work  with  executable  module colorer
(colorer.exe), which could be found in bin directory.
    After that run bin/install.exe - this program will write some  paths
into windows registry - they are used by external programs.

    4 ever. Using colorer.
    If  you  use colorer as external library in external application, it
must  automatically  find  paths  to  colorer  bases. To tell the truth,
previously  colorer  worked  as  a plugin to FAR Manager shell by Eugene
Roshal  - but now it is separate program. Of course, plugin works also -
but  as  external program that uses colorer resources - you'll find it's
distributive in the same place, where you've found this one.

    3. Library sources.
    They are in src directory. All library codes you'll find in 'shared'
directory. Also there are additional programs sources:
  src/colorer   -  colorer.exe sources,
  src/pcolorer  -  FAR Manager colorer plugin sources,
  src/icolorer  -  sources for compilation library (dll) with
exported colorer functions.
  src/hrdsets   -  program to edit hrd files (win32).
    So, it's all, I think.

    5. other.
    /bin/  directory  contains  binary  executables  of colorer program.
/hrc/ directory contains HRC scripts to highlight types. You'll find all
documentation on library in /doc/ directory.
