    0. Hi all!
    This  is  colorer.  Whats  this?  hm... its only FAR Manager plugin.
Sometimes  it works good. So, what interesting are there? try to install
it - may be you are lucky...

    1. And How?
    Hm.. so... rtfm.

    2. That manual.
    It  is.  So, it is really easy to install colorer. At first you must
have archive with colorer library(not plugin). Mostly you can find it is
same  place, where you've taken colorer plugin. You must install library
first.

    2.1. And how we can do it?
    I  don't  know.  really. Read readme.txt in library distributive and
install it. So, I hope you've made it - and colorer was installed into
  c:\program files\colorer\    (or some other)

    2.1. Gibberish.
    Try  to  get  into  the  way.  Now you must install plugin. Save our
souls!  You  can't  install  plugins yet? Ohh... You must extract plugin
archive into the
  c:\program files\far\plugins\colorer\    (or you own FAR folder)

    2.2. Now you must rerun FAR Manager and... colorer is ready for
work. You can meet some problems, if colorer will not find library paths
in registry. In this case you can set these registry entries (see library
manuals), or set them with hands in plugin settings:
this is the base hrc-file:
  c:\program files\colorer\hrc\colorer.hrc
and colors assigns hrd file:
  c:\program files\colorer\hrd\console\default.hrd
    Paths could be other depending to library install path.
    You  may  wish  to choose another hrd-file - you'll find all them in
colorer/hrc/assigns  folder.  They  defines  different  color  styles of
editor. It's all - now you can start work in editor.

    3. For the love of God, Montresor!
       Yes! For the love of God!
    And what's more? hmm.. colorer has some extended features to support
pair  constructions - their highlighting, selection and jumping. Also it
can  seach  for  the lists of functions and errors in the text. All this
you'll  find  in  colorer's  menu in editor. You can use these functions
with  shortcuts  -  a kind of them defined in shortcut.reg. Also you can
use  colorer.exe  (in library distributive) - as an external viewer (FAR
cannot use colors in internal viewer) - search it for more features.
