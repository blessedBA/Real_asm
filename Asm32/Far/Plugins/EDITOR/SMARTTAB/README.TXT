
            SmartTab in the FAR editor. FREEWARE
            ====================================

                  Version 1.0,  18.02.99.


The very brief description
--------------------------

This plugin adds the new function to built-in editor. It works also, either as 
SmartTab in IDE Borland (Inprise) Delphi, C or Pascal. Exists one difference, - 
this plugin is called on Shift+Tab (not Tab). The last easy to change.


Installation
------------

1) Create subdirectory Plugins\Editor\SmartTab and extract there archive
2) Register pluguns hot key - HotKey.reg
3) Register macros - ShiftTab.reg
4) Restart FAR
